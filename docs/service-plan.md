# 누수탐지+보험 청구 지원 통합 플랫폼 (웹 서비스 기획서)

2026년 8월
작성자: 유욱모

## 1. 서비스 비전

LeakCare는 누수원인 탐지, 수리, 보험금 청구, 사후관리까지 하나의 플랫폼에서 제공하는 토탈 서비스로 정착.

주요 목표
- 누수 발생 시 모바일웹 접수
- 전문가 탐지 및 수리 연결
- 보험 보상 가능성 사전 진단
- 보험 서류 자동 생성
- 보험금 청구 진행 관리
- 모든 작업 이력 디지털 보관

## 2. 주요 사용자

| 일반고객 | 누수처리자 | 보험처리자 | 플랫폼관리자 |
|---|---|---|---|
| 아파트 거주자 | 탐지 사업자 | 고객 | 고객관리 |
| 빌라 및 주택 소유자 | 설비 사업자 | 보험청구 관리자 | 사업자 관리 |
| 임대인 및 임차인 | 방수사업자 | 손해사정 협력사 | 보험 프로세스 관리 |
| 상가 운영자 | 인테리어 사업자 | | |

## 3. 웹 사이트 구조

메인 메뉴: 홈 / 누수 접수 / 보험센터 / 진행현황 / 고객지원 / 마이페이지

## 4. 고객 서비스 플로우

- STEP 1: 누수 발생 — 고객이 웹사이트에 접속
- STEP 2: 누수 접수 — 주소 입력, 사진 업로드, 동영상 업로드, 증상 선택, 긴급도 선택
- STEP 3: 사전 진단 — 시스템 분석(천장 누수 / 욕실 누수 / 배관 누수 / 외벽 누수 / 결로 의심)
- STEP 4: 기사 배정 — 지역 기반 자동 배정, 방문 일정 예약
- STEP 5: 현장 탐지 — 누수 원인 분석, 탐지 결과 등록, 원인 보고서 생성
- STEP 6: 보험 진단 — 보험 가입 여부 확인, 보상 가능성 분석, 필요 서류 자동 안내
- STEP 7: 수리 진행 — 견적 승인, 작업 진행, 완료 보고서 작성
- STEP 8: 보험 청구 — 증빙서류 자동 생성, 보험 제출 지원, 진행 상태 추적
- STEP 9: 보험금 수령 — 고객 지급 완료

## 5. 홈 화면 설계

**Hero 영역**
- 메인 문구
- 버튼: 누수 접수하기 / 보험 상담 신청

**빠른 서비스**
- 누수 접수
- 긴급 출동 요청
- 보험 가능 여부 확인
- 견적 상담

**서비스 소개**
- 누수 탐지 — 전문 장비 활용
- 수리 서비스 — 전국 네트워크
- 보험 지원 — 청구 서류 지원
- 사후 관리 — 작업 이력 제공

> "누수 탐지부터 보험금 청구까지 한 번에 해결"

## 6. 누수 접수 페이지

- 기본 정보: 이름, 연락처, 주소
- 누수 정보: 발생 장소, 발생 시점, 피해 범위, 긴급도
- 파일 첨부: 사진 최대 20장, 동영상 업로드
- 보험 정보: 보험 가입 여부, 보험사, 증권번호
- 접수 버튼: "접수 완료"

## 7. 보험센터

**보험 진단 서비스 질문 예시**
- 아래층 피해가 있습니까?
- 본인 주택 피해입니까?
- 누수 원인을 알고 있습니까?
- 보험에 가입되어 있습니까?

**결과 화면**
- 청구 가능성 높음
- 추가 검토 필요
- 보상 제한 가능

**필요 서류 안내 (자동 체크리스트)**
- 누수 원인 확인서
- 공사 견적서
- 피해 사진
- 수리 영수증
- 세금계산서
- 통장사본

**보험 진행 현황 타임라인**
접수 → 검토 → 손해사정 → 승인 → 지급

## 8. 진행현황 페이지

**고객 확인 정보**
- 접수번호, 현재 상태, 담당 기사, 방문 일정, 견적 금액

**상태 단계**
접수완료 → 배정대기 → 기사배정 → 현장조사 → 견적제출 → 수리진행 → 보험청구 → 완료

## 9. 마이페이지

- 내 접수 내역: 진행 중 / 완료 / 취소
- 문서함: 견적서, 탐지 보고서, 보험 서류, 영수증, 세금계산서
- 보험함: 보험 접수 내역, 지급 결과, 청구 이력

## 10. 사업자 전용 페이지

- 배정 작업: 오늘 일정, 지도 보기, 고객 정보
- 현장 업무: 사진 등록, 탐지 결과 입력, 작업 완료 보고
- 보험 지원: 원인 확인서 작성, 현장 보고서 제출

## 11. 관리자 시스템

- 통합 대시보드: 금일 접수, 진행 중, 보험 청구 중, 완료 건수
- 접수 관리: 지역별 조회, 상태 변경, 기사 배정
- 보험 관리: 보험사별 현황, 손해사정 진행 현황, 승인율 관리
- 기사 관리: 기사 등록, 평가 관리, 활동 현황

## 12. 데이터베이스 핵심 구조

**보험청구**
